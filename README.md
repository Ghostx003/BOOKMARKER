- 🔀 Merge multiple sessions
- 🏷️ Organise bookmarks into groups
- 📂 Session folders
- 📌 Pin favourite sessions
- 📝 Rename sessions
- 🗑️ Delete sessions
- 📋 Copy links instantly
- 💾 JSON backup
- 📄 TXT export
- 🔄 Restore backups
- ⚡ Manifest V3 compatible
- 🦊 Firefox compatible

# 📦 Installation

## Clone the repository

```bash
git clone https://github.com/yourusername/BOOKMARKER.git
```

Move into the repository.

```bash
cd BOOKMARKER
```

---

## Browser Extension

Load the `bookmark-manager-extension` folder as an unpacked extension.

### Chrome

```
chrome://extensions
```

Enable **Developer Mode** and click **Load Unpacked**.

---

### Firefox

Open

```
about:debugging
```

Load the extension temporarily.

---

## Web Application

Simply open

```
web-app/index.html
```

or deploy the folder using Vercel, Netlify or GitHub Pages.
