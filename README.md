# BOOKMARKER

A modern, fast, and feature-rich Tab & Bookmark Management Suite.

## Project Structure

This repository is split into 2 separate folders:

### 1. [`bookmark-manager-extension/`](./bookmark-manager-extension)
- The complete browser extension (Chrome Manifest V3 & Firefox AMO compatible).
- Features one-click tab saving, session append/merge modal, link grouping, transparent icons, and full JSON/TXT backup export.

### 2. [`web-app/`](./web-app)
- The standalone Web Application view.
- Full-screen dashboard featuring modern Linear/Raycast dark theme UI, responsive layouts, and local storage management.

### Key Features:
• One-Click Session Saving: Instantly capture all open browser tabs into a single named or timestamped session.
• Session Append & Merge: Easily append open tabs to existing sessions or merge multiple sessions into one.
• Smart Link Grouping: Automatically shuffle and organize active links into manageable study or work groups.
• Premium Dark Mode UI: Enjoy a clean, fast, and responsive interface inspired by modern productivity apps.
• In-App Modals: Manage, rename, and organize your sessions seamlessly without annoying browser popups.
• Full Backup & Export: Export your entire bookmark history or individual sessions to JSON and TXT files for safekeeping and easy recovery.
Keep your browser clean, reduce memory usage, and never lose an important link again!
