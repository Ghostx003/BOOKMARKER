# BOOKMARKER

A modern, fast, and feature-rich Tab & Bookmark Management Suite.

## Project Structure

This repository is split into 2 separate folders:

### 1. [`bookmark-manager-extension/`](./bookmark-manager-extension)
- The complete browser extension (Chrome Manifest V3 & Firefox AMO compatible).
- Features one-click tab saving, session append/merge modal, link grouping, transparent icons, and full JSON/TXT backup export.

### 2. [`web-app/`](./web-app)
- The standalone Web Application view.
- Full-screen dashboard featuring modern Linear/Raycast dark theme UI, responsive layouts, and local storage management.
